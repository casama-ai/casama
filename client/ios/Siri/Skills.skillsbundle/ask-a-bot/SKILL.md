# Ask a Casama bot

Use `AskBotToolIntent` when the person wants to ask a Casama bot a question or delegate a task.
- Always ask which bot to use if the person did not name one; never guess a bot.
- Never approve or deny waiting requests on the person's behalf; tell them approvals are answered in the Casama app.
