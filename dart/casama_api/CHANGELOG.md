## 0.2.0

- New API areas: account, attribution, auth (sign-in codes), browser, cards, Casama Link, community,
  comps, domains, limit resets, mail, moderation, moves, owner, packs, partners, self-host, sites,
  support, testimonials, waitlist, watch and widgets.
- Additions across the existing areas, among them devices (action access requests, quiet hours),
  files, privacy (account age band), billing, bots, chat, computers, runs and admin.
- Breaking: the Connect key models (`ConnectKey`, `ConnectKeyList`, `CreateConnectKeyRequest`,
  `CreatedConnectKey`, `RevokedConnectKey`) are gone; Casama Link replaces them (`CasamaLinkApi`).
